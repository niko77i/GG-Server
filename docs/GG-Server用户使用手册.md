## 1. 系统概述

GG-Server 是一套 **Google Ads 账户管理与广告数据报表平台**，核心解决两个问题：

| 功能 | 说明 |
|------|------|
| 📊 **自动做表** | 粘贴原始广告数据 → 一键解析 → 自动写入 Google Sheets，省去手动填表 |
| 👥 **账户管理** | 统一管理 Google Ads 账户（存活/死亡/验证/限额），支持软删除、批量导入、MCC 归属 |

**技术架构**：Python Flask 后端 + Vue 3 前端 + SQLite 数据库 + Google Sheets API

## 3. 自动做表

> 将广告投放平台的原始数据，自动解析并写入 Google Sheets，省去手动复制粘贴、排版的工作。

### 3.1 功能流程总览

```
粘贴原始数据 → 一键解析 → 选择产品/日期 → 解析为结构化报表 → 更新到 Google Sheets
                                                         ↓
                                                  同时存入数据库（数据分析用）
```

### 3.2 实操：完整做表流程

#### 第 1 步：进入工具集

点击左侧导航栏「🧰 工具集」，默认打开「📊 做表数据」标签页。

![做表数据界面示意图](界面包含：产品选择器、日期选择器、养户关键词输入框、原始数据输入框)

#### 第 2 步：选择产品与日期

1. 在 **「搜索并选择产品…」** 下拉框中搜索你要投放的产品名称
2. 在 **日期选择器** 中选择报表日期
3. （可选）在 **「养户关键词」** 中输入关键词，系统会自动将匹配的行标记为"养户"

> **提示**：产品下拉框列出了所有你在系统中配置的产品。如果找不到你的产品，请联系管理员在「产品管理」中添加。

#### 第 3 步：粘贴原始数据

将从广告平台（如 Google Ads）复制的原始竖排数据粘贴到大文本框中。

**支持的数据格式**：

- **标准格式**（11 列）：包含广告系列 ID，系统自动剔除第 5 列
- **养户格式**（7 列）：账号 / 客户ID / 广告系列 / 状态 / 费用 / 展示 / 点击

> **勾选「包含广告系列ID」**：当原始数据中包含广告系列ID列时勾选，系统会自动处理  
> **勾选「养户」**：当数据是养户格式（7列）时勾选

数据示例（标准格式，从 Google Ads 复制）：
```
Account: 123-456-7890
Campaign: FW66-GGB-GG-G38-MyGame
Customer ID: 1234567890
Cost: $150.25
Impressions: 12,345
Clicks: 567
Installs: 89
...
```

#### 第 4 步：一键解析

点击 **「🚀 一键解析并生成所有报表」** 按钮。

系统会自动：
1. 解析粘贴的原始数据
2. 提取账户、客户ID、广告系列、费用、展示、点击、安装等指标
3. 按产品和包名聚合数据
4. 生成结构化报表

解析完成后，下方会展示：
- **按包分组明细**：每个广告系列的汇总数据
- **按账户分组明细**：每个账户的汇总数据
- **原始数据表**：所有解析出的行数据

#### 第 5 步：导出或写入表格

- **📥 导出全部为 Excel**：将解析结果下载为 Excel 文件（.xlsx）
- **📊 更新你的表格**：将数据写入你配置的 Google Sheets

点击「更新你的表格」后，系统会在后台异步将数据写入你的 Google Sheets。写入的表格包含 14 列：

| 列 | 内容 | 列 | 内容 |
|----|------|----|------|
| A | 日期 | H | 商务（销售人员） |
| B | 运营 | I | 地区 |
| C | 账号 | J | 广告系列 |
| D | 客户ID | K | （空） |
| E | 费用 | L | 代投比例 |
| F | （空） | M | （空） |
| G | 产品（养户标记为"养户"） | N | （空） |

#### 第 6 步：查看同步状态

数据写入 Google Sheets 是**后台异步执行**的，如果同步失败，界面上会显示提示条：
- ⚠️ **填表失败** — 显示错误信息，系统会在 30 秒后自动重试
- ❌ **重试失败** — 需手动点击「🔄 重新同步」按钮
- 📋 **查看数据** — 可展开查看将要写入的数据内容，也可复制 TSV 手动粘贴

### 3.3 养户模式详解

"养户"是指不归属任何产品的广告消耗数据。它们会被单独标记，在 Google Sheets 中显示为：

- **产品列（G 列）**：显示「养户」
- **商务列（H 列）**：显示「止戈」
- **代投比例列（L 列）**：显示「0%」

**使用场景**：
- 测试账户的消耗记录
- 尚未分配产品的广告系列
- 过渡期的投放数据

**操作方式**：
1. 在「养户关键词」输入框中输入关键词（如"test"、"养户"等），按回车添加
2. 系统解析数据时，广告系列名称匹配到关键词的行会自动标记为养户
3. 养户数据不会存入 ad_reports 数据分析表（避免干扰正常数据分析）

> **提示**：养户关键词支持多个，用英文逗号或回车分隔。匹配是模糊匹配，不区分大小写。

### 3.4 数据管理

点击「📋 数据管理」进入做表数据的历史记录管理页面。

**功能清单**：

| 操作 | 说明 |
|------|------|
| 🔍 筛选 | 按产品、日期范围、关键词（账户/系列/客户ID）筛选 |
| 📊 列显示 | 自定义显示哪些列（花费、展示、点击、安装等） |
| ✏️ 编辑 | 点击某行的「编辑」按钮修改数据 |
| 🗑 删除 | 删除单条或多条数据（勾选后批量删除） |
| 📥 导出CSV | 将筛选结果导出为 CSV 文件 |

### 3.5 数据分析

点击「📊 数据分析」进入仪表盘页面。

**仪表盘功能**：

- **核心指标卡片**：总花费、总展示、总安装、应用内操作、CPI、CTR、CVR
- **KPI 对比**：实际 CPI vs 目标 KPI，绿色 ✓ = 达标，红色 ✗ = 未达标
- **环比变化**：花费和安装与上期对比的涨跌百分比
- **异常提醒**：系统自动检测花费/CPI 突增等异常
- **按包/系列分组**：明细表格，支持排序
- **趋势图**：按日期查看花费和 CPI 趋势
- **产品对比**：多产品并列对比

**使用步骤**：

1. 选择产品（支持多选）、地区、日期范围
2. 点击「🔄 刷新」
3. 切换 Tab 查看不同维度：仪表盘 / 趋势 / 产品对比

## 4. 账户管理

> 统一管理 Google Ads 广告账户的全生命周期：创建、归属 MCC、状态跟踪、软删除、恢复。

### 4.1 账户列表界面

点击「👥 账户管理」进入账户列表页。

**界面布局**：

```
┌─────────────────────────────────────────────────────────┐
│ [➕新增账户] [📥批量导入] [🔍批量查户] [💰批量充值] [🔄同步] [🗑已删除] │
├─────────────────────────────────────────────────────────┤
│ [存活 N] [死亡 N] [验证 N] [限额 N] …  ← 状态快捷筛选按钮      │
├─────────────────────────────────────────────────────────┤
│ 🔍 搜索  [▼全部MCC]  [▼全部代理]  [▼全部时区]              │
├─────────────────────────────────────────────────────────┤
│  账号名称  │ 账号ID  │ 所属MCC  │ 代理  │ 状态  │ 时区  │ … │
│  ✏️ 名称A  │ 123-…  │ MCC-A   │ 代理X │ 存活  │ UTC+8 │   │
│  ✏️ 名称B  │ 456-…  │ MCC-B   │ 代理Y │ 死亡  │ UTC+0 │   │
├─────────────────────────────────────────────────────────┤
│                     ← 分页 →                             │
└─────────────────────────────────────────────────────────┘
```

### 4.2 新增账户

#### 单个新增

1. 点击 **「➕ 新增账户」** 按钮
2. 在弹出的对话框中填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 账户 ID | ✅ | Google Ads 账户 ID（格式：123-456-7890） |
| 名称 | | 自定义账户名称，方便识别 |
| 所属 MCC | | 选择要归属的 MCC |
| 代理 | | 选择代理渠道 |
| 状态 | | 存活（默认）/ 验证 / 限额 / 死亡 |
| 时区 | | 账户所在时区（如 UTC+8） |

3. 点击「确认」保存

#### 批量导入

1. 点击 **「📥 批量导入」** 按钮
2. 在弹出的对话框中粘贴账户 ID 列表（每行一个）

   支持的输入格式：
   ```
   123-456-7890
   234-567-8901 账户A
   345-678-9012 | 代理X | UTC+8
   4567890123
   ```

3. 系统自动识别并显示：
   - ✓ **新账户**（可以导入的）
   - 🔒 **已属于你**（无需重复导入）
   - ⚠ **他人账户**（可选择认领）
   - ✕ **格式不符**

4. **认领他人账户**：对于他人名下的账户，可先编辑信息（名称、时区、代理、状态、MCC），再勾选认领
5. 点击「确认导入」

### 4.3 编辑账户

账户列表中的以下字段支持**行内编辑**（点击 ✏️ 图标即可修改）：

- **账号名称**：点击 ✏️ → 输入新名称 → 回车或失焦保存
- **所属 MCC**：点击 ✏️ → 下拉选择新 MCC → 自动保存

### 4.4 查看账户详情

点击表格中某个账户行的任意位置，弹出详情对话框，包含：

- 基本信息（名称、ID、MCC、代理、状态、时区）
- **MCC 变更历史**：该账户被移动到不同 MCC 的记录
- **充值记录**：该账户的历史充值记录

### 4.5 批量操作

勾选多个账户后，可以使用以下批量功能：

| 功能 | 说明 |
|------|------|
| 💰 批量充值 | 为选中的账户批量提交充值记录 |
| 批量修改状态 | 下拉选择新状态，自动应用到所有选中账户 |
| 批量修改 MCC | 下拉选择新 MCC，自动应用到所有选中账户 |
| 🗑 批量删除 | 软删除选中的账户（可恢复） |

### 4.6 删除与恢复（软删除）

GG-Server 使用**软删除**机制，删除的账户不会立即从数据库移除，而是标记为已删除状态。

#### 删除账户

1. 单条删除：点击账户行末尾的删除按钮
2. 批量删除：勾选多个账户 → 点击「🗑 批量删除」

> ⚠️ 删除操作会同时将 Google Sheets「我的看板」中该账户的 H 列标记为"解绑"

#### 查看已删除账户

点击 **「🗑 已删除」** 按钮，弹出已删除账户列表：

- 支持搜索筛选（按 ID / 名称 / 代理）
- 显示原归属 MCC、删除时间等信息

#### 恢复账户

在已删除列表中，点击某账户的 **「恢复」** 按钮：
- 账户状态恢复为正常
- 重新出现在账户列表中

#### 物理删除（不可恢复）

在已删除列表中，点击某账户的 **「物理删除」** 按钮：
- ⚠️ **此操作不可逆！** 账户数据将被永久删除
- 系统会弹出确认对话框，需二次确认

### 4.7 同步 — 我的看板

这是连接 Google Sheets 与系统的核心功能，实现双向数据同步。

#### 操作步骤

1. 在账户列表页点击 **「🔄 同步」** 按钮
2. 系统自动读取你的 Google Sheets「我的看板」工作表（A:H 列）
3. 与系统中的账户数据进行比对，显示差异报告：

   | 类型 | 说明 |
   |------|------|
   | 🆕 新增账户 | Sheet 中有但系统中没有的账户，将自动创建 |
   | ⚠️ 状态变更 | 系统状态与 Sheet 不一致的账户（如封户→死亡） |
   | ✅ 无变化 | 两边数据一致的账户 |

4. 确认后点击 **「确认同步」**：
   - 新账户自动创建到系统中
   - 状态不一致的账户自动更新（可取消勾选某些不确认的变更）
   - 同步完成后，系统的状态也会回写到 Sheet 的备注列

#### 数据映射规则

| Sheet 列 | 对应字段 | 说明 |
|----------|---------|------|
| A 列 | 运营 | 用于权限校验，只有匹配当前用户才允许同步 |
| B 列 | 账户 ID | 唯一标识 |
| C 列 | 代理/渠道 | 对应系统代理选项 |
| D 列 | （保留） | |
| E 列 | 时区 | 账户时区 |
| F 列 | 备注 | 同步后系统会回写状态到此列 |
| G 列 | 封户标记 | "是"→建议状态"死亡"；"否"/"可用"→建议"存活" |
| H 列 | 解绑标记 | "解绑"的行会被跳过；删除账户时系统会写入"解绑" |

#### 注意事项

- 同步只识别 **A 列运营名称** 与当前登录用户匹配的行
- H 列标记为"解绑"的行会被跳过
- 首次同步建议做 dry_run（预览模式），确认无误后再执行

### 4.8 充值记录

#### 提交充值

1. 单个充值：点击账户行的充值按钮，填写金额、代理、操作人、状态
2. 批量充值：勾选多个账户 → 点击「💰 批量充值」，一次性提交多笔

#### 查看充值记录

在账户详情弹窗中，可以查看该账户的全部历史充值记录，包括：金额、代理、操作人、状态、提交时间。

#### 充值与 Google Sheets 联动

充值时系统会**双写**：
1. 先写入本地数据库
2. 后台异步写入 Google Sheets 充值表

如果 Sheets 写入失败，可以在充值记录中点击「重试 Sheets 同步」。

#### 死亡清账

当账户状态变更为"死亡"时，系统会**自动追加一条金额为「清」的充值记录**，方便在充值表中对账。

### 4.9 MCC 管理

MCC（My Client Center）是 Google Ads 的经理账户，用于统一管理多个广告账户。

#### 界面入口

在账户管理页面切换至「MCC 管理」标签页（或通过左侧导航进入）。

#### 新增 MCC

1. 点击「新增 MCC」
2. 填写：
   - **名称**：自定义 MCC 名称（如"主账户-美国"）
   - **MCC ID**：Google Ads 的 MCC ID（格式：123-456-7890）
   - **等级**：选择 MCC 等级（一级/二级等，需先在设置中配置）
   - **父 MCC**：如果是子 MCC，选择上级 MCC

#### MCC 关联账户

在 MCC 详情页可以查看该 MCC 下关联的所有广告账户，方便按 MCC 维度管理。

## 5. 数据分析

### 5.1 仪表盘

支持按产品、地区、日期范围筛选，查看：

| 指标 | 计算方式 |
|------|---------|
| 总花费 | 所有广告系列费用之和 |
| 总展示 | Impressions 总和 |
| 总安装 | Installs 总和 |
| 应用内操作 | In-app Actions 总和 |
| CPI | 花费 ÷ 应用内操作数 |
| CTR | 点击 ÷ 展示 × 100% |
| CVR | 安装 ÷ 点击 × 100% |

### 5.2 KPI 监控

如果产品设置了 KPI（目标 CPI），仪表盘会自动对比：
- ✓ **达标**（绿色）：实际 CPI ≤ KPI
- ✗ **未达标**（红色）：实际 CPI > KPI

### 5.3 异常检测

系统自动检测数据异常：
- 花费突增（日花费超过均值 3 倍标准差）
- CPI 突增
- 展示/点击为 0 但有花费

## 6. 系统设置

### 6.1 账户选项配置

进入 **设置 → 账户设置**，可管理以下下拉选项：

| 选项类型 | 说明 | 示例 |
|---------|------|------|
| 🏢 代理 | 广告代理渠道 | 代理X、代理Y |
| 📊 状态 | 账户状态类型 | 存活、死亡、验证、限额 |
| ⭐ MCC 等级 | MCC 等级分类 | 一级、二级 |
| 👤 销售人员 | 商务/销售名单 | 张三、李四 |

**操作方式**：
- 双击标签 → 编辑名称
- 点击标签 × → 删除
- 点击 + → 新增选项

### 6.2 Google Sheets 配置

#### 全局充值表配置（管理员）

在设置页面的「📊 充值表配置」卡片中：
1. 粘贴 Google Sheets 链接或 Spreadsheet ID
2. 点击「📋 读取工作表」验证连接
3. 配置工作表名称映射（充值表、已接账户明细、我的看板）

#### 个人 Google Sheets 配置

在个人中心或个人设置中：
1. 添加 Google Sheets 表格 ID
2. 可选择特定的 Sheet（工作表）
3. 支持配置多个表格，并标记一个为激活状态

## 7. 常见问题

### Q1：做表数据粘贴后解析不出来？

**检查项**：
- 确认数据格式正确（从 Google Ads 直接复制的报表数据）
- 确认已正确勾选"包含广告系列ID"或"养户"复选框
- 确认产品已选择，且产品下的包系列名称与数据中的广告系列能匹配

### Q2：「更新你的表格」点完后没有反应？

- 做表数据写入 Google Sheets 是**后台异步**执行的
- 界面会显示同步状态条：同步中 → 成功/失败
- 如果失败，检查：Google Sheets 配置是否正确、服务账号是否有表格编辑权限
- 失败后系统会自动重试，也可以手动点击「🔄 重新同步」

### Q3：同步「我的看板」时报错"这不是你的私有看板表"？

- 系统会检查 Sheet 的 A 列（运营列）
- 只有 A 列中包含你登录用户名（display_name）的行才会被同步
- 解决方案：在 Sheet 的 A 列填写你的运营名称，或联系管理员修改你的 display_name

### Q4：删除的账户能恢复吗？

- **可以**。点击「🗑 已删除」按钮查看已删除账户列表，点击「恢复」即可
- 注意：「物理删除」操作不可逆，会永久删除

### Q5：如何批量修改多个账户的 MCC？

1. 在账户列表中勾选需要修改的账户
2. 在顶部的「批量修改 MCC」下拉框中选择目标 MCC
3. 自动保存，系统会记录 MCC 变更历史

### Q6：Google Sheets 配置不生效？

**检查项**：
1. 确认服务账号 JSON 密钥文件已正确部署到服务器
2. 确认已将服务账号邮箱添加为 Google Sheets 的编辑者
3. 确认表格 ID 输入正确（从表格 URL 中复制）
4. 确认 Sheet 名称与配置中的映射名称一致

### Q7：支持哪些时区？

时区列表是动态的下拉选项，包含主流时区（UTC-12 到 UTC+14），支持输入筛选。常用时区：
- UTC+8（北京时间）
- UTC+0（伦敦）
- UTC-5（美东时间）
- UTC-8（美西时间）
