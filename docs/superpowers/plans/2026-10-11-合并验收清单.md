## 准备（都由你执行；我不启动任何进程）

1. `cd frontend && npm run build`
2. 重启 Flask

> **为什么只能靠这份清单**：本仓库**没有组件测试框架**（`node --test` 只跑纯逻辑 `.mjs`，
> 测不到 `.vue` 的渲染）⇒ 前端那些改动**只能**在真实浏览器里、按本清单逐条验。
> `npm test` / `npx vite build` 只保证纯逻辑与构建通过，不覆盖 `.vue` 渲染。

**共用前置（各批清单里重复出现，已合并到此）**

- 打开 TT 设置页的「户管看板」卡片；确认「户类型」里至少有 **企业户** 与 **加白户** 两张表，
  且各自的工作表名已保存（点过「💾 保存配置」）。
- **每张要验的表里必须有一列表头叫「账户ID」**（定位键，否则同步与读表头都会被拒）。
- 建议在**测试用表格**上做（清单里要往表里加 / 改名一列、清空工作表名、填系统没有的名字）。
- 打开 **F12 → Network** 面板——多处「到底有没有真的发请求」要靠它判定。
- 备好两个观测点：① **账户详情**（看账户挂没挂上 BC / 渠道）；② **下拉出现的地方**（看新建的 BC / 渠道是否立刻可选）。

### B.3 `［TT表头］` · A8 的「一个已知边角（不用修，知道就行）」
