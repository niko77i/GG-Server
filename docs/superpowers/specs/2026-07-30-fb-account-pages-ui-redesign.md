# FB 账户管理页面 UI 美化设计文档

> 日期: 2026-07-30 | 状态: 已确认

## 1. 需求描述

美化 FB 平台"账户管理"导航下全部 5 个页面的 UI，统一视觉风格，提升可用性和美观度。

**涉及页面：**
- 产品管理 (`FbProductPanel.vue`)
- 广告账户 (`FbAccountPanel.vue`)
- 账户BM管理 (`FbBmPanel.vue`)
- 像素BM管理 (`FbPixelBmPanel.vue`)
- FB设置 (`FbSettingsPanel.vue`)

**约束：** 不改 `<script setup>` 逻辑，只改 `<template>` 和 `<style scoped>`。

## 2. 设计系统

### 2.1 配色与基础
- 页面背景：`#f5f6f8`
- 卡片：`#fff`、圆角 `12px`、阴影 `0 1px 3px rgba(0,0,0,0.06)`
- 主色调：沿用 Element Plus `#1890ff`
- 统计卡片 hover 微动效（上移 2px + 阴影增强）

### 2.2 通用组件规范
- **页面头部**：标题 20px/700 + 操作按钮 flex 两端对齐
- **统计卡片行**：4 列 `el-row` 栅格，每列小卡片含图标/数值/标签
- **筛选栏**：浅灰底卡片包裹，控件间距 12px
- **数据区**：表格包在白色卡片中，表头深色加粗，hover 增强
- **弹窗**：统一 `width="520px" top="5vh"`

## 3. 各页面具体方案

### 3.1 产品管理
- 顶部统计：总产品 / 正常 / 已暂停 / 我的
- 筛选栏卡片化重构
- 产品卡片微调圆角阴影
- 展开区线名表格样式优化

### 3.2 广告账户
- 顶部统计：总账户 / 关联 BM 数 / 今日新增
- 筛选栏卡片化，批量删除按钮移入表格卡片头部
- 表格包进卡片

### 3.3 账户BM管理
- 顶部统计：总 BM / 正常 / 已封禁 / 关联账户总数
- 表格卡片化，封禁弹窗优化

### 3.4 像素BM管理
- 顶部统计：总像素 BM / 总像素数
- 表格卡片化，像素管理弹窗优化

### 3.5 FB设置
- 三栏并排卡片（地区/商务/状态）
- 每栏卡片内 inline 添加表单 + 紧凑列表（tag + 删除）
- 空状态 el-empty 占位

## 4. 不涉及
- 路由结构（已在 AppSidebar.vue 中调整完毕）
- API 调用逻辑
- 引入新依赖
