# SettingsPanel UI 美化设计

## 需求描述

美化 [SettingsPanel.vue](../../../frontend/src/views/SettingsPanel.vue) 设置页面的 UI，从当前的原始表格布局改为卡片式分区设计，提升视觉层次和用户体验。

## 当前问题

1. 四个选项管理区域用 `el-table` 直接并排，视觉上像后台管理列表而非设置页
2. 表格行内编辑体验生硬——点击单元格切换为 input，无过渡
3. 删除按钮常显（🗑 emoji），视觉噪音大
4. 充值表配置与选项管理混在同一 Tab，无功能分区感
5. 新增选项的 input + 按钮占用单独一行，不够紧凑
6. 缺少空状态和加载状态展示

## 设计方案

### 整体风格

卡片式分区（与 UserProfileView 风格一致），每个功能模块独立成卡，视觉层级分明。保持 Element Plus 组件库，不引入新依赖。

### Tab 1: 账户设置

#### 选项管理卡片（4 张，2x2 网格排列）

每个选项类型（状态/代理/MCC 等级/商务人员）一张卡片：

```
┌──────────────────────────────────┐
│ 📊 账户状态选项              3项 │  ← el-card header
│                                  │
│ [存活 ×] [死亡 ×] [验证 ×] [+]  │  ← Tag 标签 + 悬浮×删除 + 新增按钮
│                                  │
│ 新增: [__________] [确认]        │  ← 紧凑新增栏（点击+展开）
└──────────────────────────────────┘
```

**交互改进：**
- 选项展示：从表格行 → `el-tag` 标签，不同选项用不同色彩（closable，点击 close 触发删除确认）
- 编辑：双击 Tag 弹出小型 `el-input` 内联编辑，回车/失焦保存
- 删除：Tag 自带的关闭按钮（×），替代原来的 🗑 按钮
- 新增：点击 "+" Tag 展开输入框，输入名称后回车确认
- 空状态：无选项时显示 "暂无选项" 提示

**字段映射：**
- 账户状态 → `store.options.statuses`
- 代理名 → `store.options.agents`
- MCC 等级 → `store.options.mccLevels`
- 商务人员 → `store.options.salesPersons`

#### 充值表配置卡片（仅管理员/开发者可见）

独立卡片，视觉上与选项卡片区分（使用 `el-divider` 上方独立展示，或调整卡片样式）：

- Google Sheets URL 输入 + "读取工作表" 按钮（保持现有交互）
- Sheet 映射下拉框列表（保持现有 `SHEET_MAPPING_META` 注册表）
- 保存按钮

### Tab 2: 地区时区

**卡片列表布局**（替代 `el-table`）：

```
┌──────────────────────────────────┐
│ 🌍 地区时区配置                   │
│                                  │
│ ┌──────────┬───────────────────┐ │
│ │ 美国     │ [UTC-5 ▼]     [×] │ │  ← 每行：地区名 + 时区下拉 + 删除
│ │ 日本     │ [UTC+9 ▼]     [×] │ │
│ │ 中国     │ [UTC+8 ▼]     [×] │ │
│ └──────────┴───────────────────┘ │
│                                  │
│ 新增: [____] [UTC+8 ▼] [确认]   │  ← 底部新增栏
└──────────────────────────────────┘
```

- 地区名只读展示，时区通过 `el-select` 切换
- 删除按钮仅在 hover 时显示
- 空状态：无地区时显示提示

### Tab 3: 数据管理

当前已用卡片，保持结构，微调：

- 导入卡片增加文件格式图标提示
- 导入历史表格分页（如果数据 > 10 条）
- 确认间隔和阴影与其他卡片统一

## 涉及文件

| 文件 | 改动 |
|------|------|
| `frontend/src/views/SettingsPanel.vue` | 核心改动：模板重构为卡片布局、脚本逻辑适配 Tag 交互 |
| `frontend/src/assets/global.css` | 可能需要新增少量样式 |

## 数据结构

无后端改动。所有数据沿用现有 store 和 API：
- `store.options.statuses / agents / mccLevels / salesPersons` — 选项列表
- `store.load*()` / `store.create*()` / `store.rename*()` / `store.delete*()` — CRUD
- `store.settings` / `store.saveSettings()` — 充值表配置
- `regionList` — 地区时区

## 技术要点

1. **Tag 内联编辑**：用 `v-if` 切换 Tag 显示/编辑状态，点击 Tag 或双击时进入编辑
2. **新增展开**：点击 "+" Tag → 展开输入框行 → 输入后回车确认 → 收起
3. **删除确认**：Tag closable 点击 × 时弹出 `ElMessageBox.confirm` 确认
4. **防抖**：编辑失焦保存无需防抖（本身就是单次操作），但需防止重复提交（加 loading 状态）

## 不在范围内

- 不新增第三方依赖
- 不修改后端 API
- 不改变现有功能逻辑（CRUD 行为不变）
- 不重构 store 层
