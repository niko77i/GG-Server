# 批量查户功能 — 设计文档

## 需求描述

在账户管理页面增加"批量查户"功能：用户可以粘贴一批账户 ID，快速查看这些账户在系统中的详细信息（归属、状态、代理、MCC 等），不需要走批量导入流程。

## 与现有功能的区别

| 功能 | 批量导入 | **批量查户（新）** |
|---|---|---|
| 入口 | AdsAccountPanel → "📥 批量导入" 按钮 | AdsAccountPanel → "🔍 批量查户" 按钮（新增） |
| 用途 | 导入/认领新账户 | 纯查询，快速了解一批账户的状态 |
| 流程 | 解析ID → 查库 → 区分新旧 → 编辑 → 提交创建/认领 | 输入ID → 查库 → 展示结果 → 完成 |
| 后端 | batch-lookup（已有） | **复用** batch-lookup 接口 |

## 技术方案

### 后端：复用已有接口

已有 `POST /api/accounts/batch-lookup`（[main.py:2840](py/main.py#L2840)）功能完全满足查户需求：

- 输入：`{ account_ids: ["123-456-7890", ...] }`
- 输出：`{ found: [...], not_found: [...] }`
- found 中每个账户包含：id, name, account_id, timezone, agent, status, acquired_date, mcc_id, mcc_name, mcc_code, owner_id, owner_name

**不需要改后端**。

### 前端：新增批量查户弹窗

#### 1. 新建组件 `AccountBatchLookupModal.vue`

核心功能：
- Textarea 输入区：粘贴账户 ID（每行一个，自动解析提取）
- 解析统计：识别数量、格式不符数量
- 查询按钮：调用 `accountsApi.batchLookup()`
- 结果表格：展示 find 的账户详情 + not_found 列表

结果展示字段：

| 列 | 说明 |
|---|---|
| 账户 ID | account_id |
| 名称 | name |
| 所属 MCC | mcc_name (mcc_code) |
| 时区 | timezone |
| 代理 | agent |
| 状态 | status（彩色标签） |
| 到手时间 | acquired_date |
| 归属人 | owner_name |

#### 2. 修改 AdsAccountPanel.vue

在工具栏加一个"🔍 批量查户"按钮，点击打开 `AccountBatchLookupModal`。

### 涉及的文件
